# Structured Knowledge Workspace

Structured Knowledge Workspace is a framework-independent tool for people and agents to manage, structure, connect, find, and govern information. Its future vision includes:

- Manage Entries
- Structure Information
- Connect Information
- Find Information
- Govern Changes

The project starts with an API-first and contract-first approach, using OpenAPI as the source of truth for the HTTP contract.

Initial stack: Kotlin, Spring Boot, Gradle Kotlin DSL, and OpenAPI Generator.

Status: local bootstrap; business capabilities are pending.
